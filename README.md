# База данных «Контора»

Приложение для работы с отделами, сотрудниками, предприятиями, договорами, счетами, платежами и прайс-листом. Данные хранятся в MySQL. Серверная часть написана на Node.js с использованием Express, клиентская — на HTML, CSS и JavaScript.

В приложении доступны просмотр, добавление, изменение и удаление записей во всех восьми таблицах.

## Требования

- Node.js 18 или новее и npm
- MySQL Server
- MySQL Workbench для просмотра диаграммы и работы с базой

## Подготовка базы данных

1. Подключитесь к MySQL Server в MySQL Workbench.
2. Откройте файл `01_schema.sql` через **File / Open SQL Script** и выполните его целиком. Будет создана база `kont4_1is_kuchenkov` с восемью таблицами.
3. Таким же образом выполните `02_data.sql`, чтобы заполнить таблицы примерами. Оба файла предназначены для первоначального создания базы и запускаются один раз.
4. Обновите список **Schemas** в Workbench. Примеры запросов к базе находятся в `03_queries.sql`.

Для просмотра диаграммы откройте в Workbench файл `kuchenkov_4_1is.mwb`. Модель хранит структуру и связи таблиц; сами данные находятся в MySQL Server.

## Запуск приложения

Склонируйте репозиторий и перейдите в папку проекта:

```powershell
git clone https://github.com/bcuseU/ispravlenie-APP.git
cd ispravlenie-APP
```

Установите зависимости:

```powershell
npm ci
```

В том же окне PowerShell задайте параметры подключения к MySQL и запустите сервер:

```powershell
$env:DB_HOST = '127.0.0.1'
$env:DB_PORT = '3306'
$env:DB_USER = 'root'
$env:DB_NAME = 'kont4_1is_kuchenkov'
$env:DB_PASSWORD = Read-Host 'Пароль MySQL'
npm start
```

Укажите адрес, порт и пользователя своего MySQL Server. Если для пользователя пароль не задан, вместо `Read-Host` используйте `$env:DB_PASSWORD = ''`.

Откройте в браузере [http://127.0.0.1:5000](http://127.0.0.1:5000). Сервер Node.js одновременно предоставляет REST API и файлы клиентской части, поэтому отдельно запускать фронтенд не нужно. Для остановки сервера нажмите **Ctrl+C** в окне PowerShell.

## API

Для каждой таблицы доступны запросы списка и отдельной записи, создание, изменение и удаление. Например, для предприятий:

| Метод | Адрес | Действие |
|---|---|---|
| `GET` | `/api/firms` | Список предприятий |
| `GET` | `/api/firms/1` | Предприятие с номером 1 |
| `POST` | `/api/firms` | Добавить предприятие |
| `PUT` | `/api/firms/1` | Изменить предприятие |
| `DELETE` | `/api/firms/1` | Удалить предприятие |

Тела `POST` и `PUT` передаются в формате JSON с именами столбцов таблицы. Для других таблиц используются разделы `departments`, `staff`, `contracts`, `bills`, `payments`, `prices` и `items`. В адресах записей с составным ключом его значения разделяются запятой, например `/api/payments/1,2`. Описание таблиц доступно по адресу `GET /api/tables`.

MySQL не позволит удалить запись, на которую ссылаются другие данные. Значения составных ключей при редактировании не изменяются: для изменения ключа нужно создать новую запись.

## Файлы проекта

- `01_schema.sql` — создание базы и таблиц.
- `02_data.sql` — заполнение таблиц примерами данных.
- `03_queries.sql` — примеры SQL-запросов.
- `kuchenkov_4_1is.mwb` — модель и диаграмма MySQL Workbench.
- `server.js` — сервер и REST API.
- `static/index.html` и `static/app.js` — интерфейс приложения.
- `package.json` и `package-lock.json` — зависимости Node.js.
